Architecture

Single-file Pygame simulation documented from the live implementation in main.py.

Overview

This project is organized as a single module with a setup function, an event loop, a physics/update step, and a render step. The data model is a list of mutable square dictionaries that are updated in place each frame.

`main.py` imports `pygame` for runtime behavior, `random` for square initialization and jitter, and `typing` for annotations.

Primary Sequence

sequenceDiagram participant R as "run()" participant C as "Clock" participant E as "handle_events()" participant U as "update_squares()" participant D as "draw_squares()" participant L as "Lifecycle" R->>R: initialize screen, clock, font, and squares loop every frame R->>C: clock.tick(FPS) C-->>R: dt R->>E: poll events alt quit or escape pressed E-->>R: True R->>R: stop loop else keep running E-->>R: False R->>U: update all squares loop each square U->>U: find closest small square alt smaller square exists U->>U: apply chase force end U->>U: find closest big square alt bigger square exists U->>U: apply flee force U->>U: clamp velocity to max_speed end U->>U: apply jitter when timer reaches interval U->>U: move square by velocity * dt U->>U: bounce off window edges U->>U: add dt to age alt age >= life_span U->>L: mark square for rebirth end end U-->>R: updated squares R->>D: render squares and HUD text D-->>R: frame displayed end end

This sequence follows the real frame path in main.py: event handling happens before update, update mutates the entity list in place, and drawing happens last.

Data Flow Notes

  • squares is created once, then mutated by update_squares() and read by draw_squares().
  • dt comes from clock.tick(FPS) / 1000.0 and scales velocity, jitter timing, movement, and aging.
  • Rebirth uses reverse-index removal so list mutation does not break iteration.

Key Functions

  • init_pygame() sets up the display, clock, and font.
  • create_square() builds one square with random size, speed, position, color, and lifespan.
  • create_squares() creates the initial population.
  • handle_events() exits on window close or Escape.
  • find_closest_small() and find_closest_big() scan for the nearest smaller or larger square.
  • compute_chase_vector() and compute_flee_vector() convert relative positions into normalized steering forces.
  • update_squares() applies steering, jitter, movement, bounce, aging, and rebirth.
  • draw_squares() renders the scene and HUD text.
  • run() owns the application loop.

Assumptions

The diagrams and notes reflect the current single-module repository state. No extra Python packages or runtime modules are present beyond main.py.
